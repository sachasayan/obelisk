Set up Obelisk

Start on a software panel, then use the same browser remote with a physical LED installation.

Local simulator Raspberry Pi setup Remote controls Troubleshooting

Run the local simulator

You need Git, Node.js 24.22.3 or later in the 24.x series or Node.js 26.x, and npm 11.

git clone --branch maintenance/modernize --single-branch https://github.com/sachasayan/obelisk.git
cd obelisk
npm ci --ignore-scripts
npm run simulate

Open http://127.0.0.1:3001/display. Switch between 2D panel and 3D installation and pick a mode from the docked remote.

Try a different layout

The format is COLSxROWS:CHAINxPARALLEL. This example starts with a blank 32 × 32 pixel panel made of four 16 × 16 tiles.

OBELISK_SIM_LAYOUT=16x16:2x2 OBELISK_START_MODE=off npm run simulate

Run on a Raspberry Pi

Use a Raspberry Pi running 64-bit Raspberry Pi OS, compatible RGB matrix panels, a GPIO adapter, the right ribbon and power cables, and a power supply sized for your panels. Follow the upstream driver’s wiring and mapping instructions for your specific hardware.

Clone Obelisk using the commands above. On the Pi, install the supported Node.js and npm versions, build-essential, and python3. Then install dependencies and build the native driver from the checkout.

npm ci --ignore-scripts
npm rebuild rpi-led-matrix

In packages/obelisk-server/config.ts, set initPanel: true. Match rows, columns, tile counts, scan options, mapping, and brightness to your installation before starting the app.

npm run clientbuild
npm run obelisk

The local remote defaults to http://127.0.0.1:3001/. To use a phone, start with HOST=0.0.0.0 npm run obelisk and open the Pi’s local IP address on port 3001. The remote is unauthenticated, so keep it on a trusted network.

Use the remote

  • Visuals includes Clock, Billboard, Lava Lamp, Pulse, Starry Night, and Sunlight. Only the active mode runs.
  • Pulse lets you pick a color and adjust intensity. Clock offers three font styles and a color picker. Lava Lamp lets you choose a palette, adjust speed, and change the number of blobs.
  • Stack Duel and Deep Scan are playable solo or with a second remote. Both players choose the same game to join. Signal Run and Echo Keys are solo.
  • Drag the four-way pad, or use arrow keys and WASD. Space and Enter trigger the game’s action while you’re focused on the controller or simulator preview.
  • Device Settings in the simulator previews Sunlight at any hour and adjusts virtual tile dimensions, arrangement, and brightness. Applying a different geometry restarts the active mode.
  • Pong opens a vertical drag surface for a paddle. Lightcycles plays an automatic round.
  • Turn display off stops the mode and blanks the panel. Set OBELISK_START_MODE=off to start blank.

Troubleshooting

  • Port already in use. Use PORT=3002 npm run simulate, then open http://127.0.0.1:3002/display.
  • 3D unavailable. Enable WebGL in your browser or use the 2D view. Both receive the same live pixel frame.
  • Phone cannot connect. Check it is on the same trusted network, the server is listening on a LAN interface, and you used the Pi’s local address and port.
  • Panel shows the wrong pattern. Run OBELISK_START_MODE=test npm run obelisk to check dimensions, scan options, chain order, and brightness against your panel model.

See the repository README and source for configuration and development details.
